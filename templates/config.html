Subnets

Subnet-based tracking: register an L3 segment here (its CIDR, and which DNS server is the "primary" for it) and devices in it can be tracked by MAC address instead of being polled directly — see Track a New Host below. The primary server is polled once per cycle for the segment's live IPv6 prefix; every device in the subnet computes its own address from that prefix, no per-device connection needed.
