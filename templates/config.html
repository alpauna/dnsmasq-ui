Backup & Restore

Backup Configuration: Download your complete DNS configuration (zones, records, servers, global settings) as a JSON file.

This backup includes all zones, DNS records, server definitions, and settings. Use it to:

  • Backup configuration before making changes
  • Transfer configuration to another instance
  • Version control your DNS configuration
  • Restore to a previous state if needed
Restore Configuration: Upload a previously backed-up JSON file to restore your DNS configuration.

Restore Options

Restore & Deploy: This will restore your configuration and automatically push the changes to all DNS servers (dns01, dns02, dns03). The dnsmasq service will be restarted on each server.
